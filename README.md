# Bootcamp Mission 09 - FashionMNIST 조건부 이미지 생성

## 1. 개요
FashionMNIST 데이터셋을 활용해 클래스 조건에 맞는 패션 이미지를 생성한 미션입니다.

## 2. 목표
조건부 생성 모델을 설계하고 학습 안정성 및 생성 결과를 개선하는 것을 목표로 했습니다.

## 3. 사용 기술
- Python
- numpy
- matplotlib
- torch
- torchvision
- torchmetrics

## 4. 주요 기능
- FashionMNIST 데이터 로드
- 조건부 생성 모델 구현
- 학습 안정화 실험
- 생성 이미지 결과 분석

## 5. 실행 방법
```bash
pip install -r requirements.txt
jupyter notebook notebooks/mission09.ipynb
```

## 6. 주요 파일
- `notebooks/mission09.ipynb`

## 7. 폴더 구조
```text
bootcamp-mission-09
  .gitignore
  notebooks/
    mission09.ipynb
  README.md
  requirements.txt
```

## 8. 학습 내용
생성 모델의 학습 흐름과 조건 정보를 활용한 이미지 생성 방식을 학습했습니다.

## 9. 트러블슈팅
미션을 진행하며 발생한 오류와 해결 과정은 노트북 또는 보고서에 정리했습니다.

## 10. 결과 화면
결과 이미지는 노트북 출력, 보고서 또는 `images/` 폴더에서 확인할 수 있습니다.

## 11. 공개 전 확인 사항
- 제출 노트북만 포함했으며, 원본 데이터와 모델 파일은 공개 범위 확인 전 포함하지 않았습니다.
